Mapa Geoespacial — BrBRICS

Base principal: IBGE (malha oficial via API). Complementos: tilacog/br-atlas (TopoJSON/GeoJSON BSD), cristoferluch/GeoDadosBrasil (leve/intermediário/máximo), ggondim/ibge-cidades-com-poligonos, 0e1/localidades (ODbL — citar fonte). Use versão simplificada para celular.

Controle de camadas

Estados (IBGE oficial)

Malha completa via servicodados.ibge.gov.br. Cor por valor de licitação (exemplo).

Municípios simplificado

Recomendo tilacog/br-atlas (BSD) ou nível mínimo do GeoDadosBrasil. Evita travar no celular.

Referência de cores

igorjba/malha mostra cinco métodos de classificação (quantis, jenks, etc.).

Como usar no Google Sites

Publique esta página no GitHub Pages (repositório luiscadilhac/brbrics) e incorpore via Inserir → Incorporar → URL. Se o mapa ficar pesado, substitua a malha de municípios pela versão simplificada.
