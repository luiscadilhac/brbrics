Mapas e Satélite — sem programar

O território brasileiro de cima

Mapas de ruas, imagens de satélite e dados territoriais oficiais. Todas as ferramentas abaixo funcionam sem código — basta copiar e colar.

🗺️ Mapa de ruas — OpenStreetMap

Ver no site oficial

Mapa colaborativo do mundo todo: ruas, bairros, prédios e pontos de interesse. Sem conta, sem chave.

Como mudar o local: acesse openstreetmap.org, busque a cidade, clique em Compartilhar → HTML e cole o código aqui.

📌 Pontos oficiais — Google Meu Mapas

Criar mapa no Google

Desenhe pontos, linhas e áreas no mapa (órgãos públicos, tribunais, fiscais, etc.) e incorpore no site.

📍 Cole aqui o iframe do Google Meu Mapas
Passo: mymaps.google.com → Criar mapa → adicionar pontos → Compartilhar → Incorporar no meu site → copiar código.

Passo a passo: 1) Acesse mymaps.google.com → 2) Crie um novo mapa → 3) Adicione pontos/linhas/áreas → 4) Clique em Compartilhar → Incorporar no meu site → 5) Cole o código aqui.

🛰️ Satélite em tempo real — NASA Worldview

Acessar NASA Worldview

Imagens da Terra quase em tempo real (desde 2000): focos de incêndio, fumaça, temperatura, chuva e nuvens.

🌎 Abrir NASA Worldview

Dica: escolha camadas e data sobre o Brasil, use Compartilhar para gerar link ou baixar imagem/GIF.

Passo a passo: 1) Acesse worldview.earthdata.nasa.gov → 2) No menu de camadas, adicione ex: Focos de incêndio (VIIRS), Fumaça ou Temperatura da superfície → 3) Navegue até o Brasil → 4) Escolha a data → 5) Clique em Compartilhar e copie o link ou baixe a imagem.

🌱 Imagens de alta resolução — Copernicus Sentinel-2

Acessar EO Browser

Imagens Sentinel-2 (até 10 m de resolução), radar Sentinel-1 e índices de vegetação e água. Gratuito (algumas funções pedem cadastro).

🛰️ Abrir EO Browser

Navegue por uma área do Brasil, escolha a data, baixe a imagem ou crie timelapse.

Passo a passo: 1) Acesse apps.sentinel-hub.com/eo-browser/ → 2) Cadastro gratuito (se pedir) → 3) Busque uma cidade ou desenhe um polígono no Brasil → 4) Escolha Sentinel-2 e a data → 5) Baixe a imagem ou crie um timelapse → 6) Publique a imagem/vídeo aqui.

🇧🇷 Mapas temáticos — Dados do IBGE

Dados abertos IBGE

Malhas geográficas oficiais (estados, municípios, setores censitários) para mapas coloridos por estado/município.

📊 Criar mapa no Datawrapper 🎨 Criar mapa no Flourish

Importe o GeoJSON do IBGE, gere o mapa e cole o código de incorporação (embed) aqui.

Passo a passo: 1) Baixe o GeoJSON de estados/municípios em servicodados.ibge.gov.br → 2) Acesse Datawrapper.de ou Flourish.studio (conta gratuita) → 3) Importe o GeoJSON → 4) Escolha cor por estado/município (ex: população, número de empresas) → 5) Publique e copie o código Embed → 6) Cole aqui.

⏱️ Mudanças ao longo do tempo — Google Earth Timelapse

Acessar Timelapse

Veja a transformação de qualquer lugar do planeta desde 1984 (desmatamento, seca, expansão urbana).

⏯️ Ver Timelapse

Compartilhe o link ou baixe o vídeo/GIF e publique aqui.

Passo a passo: 1) Acesse earthengine.google.com/timelapse/ → 2) No campo de busca, digite "Amazônia" ou "Desmatamento Brasil" → 3) A linha do tempo vai de 1984 a hoje → 4) Clique em Compartilhar para copiar o link ou baixar o vídeo/GIF → 5) Publique aqui.

ℹ️ Ferramentas que exigem programação

Leaflet, OpenLayers, MapLibre GL JS, deck.gl, CesiumJS, leafmap/geemap e TorchGeo são bibliotecas para desenvolvedores. Não estão implementadas aqui porque exigem código. Caso queira adicionar futuramente, avise que gero o código pronto para colar.

📋 Como colocar qualquer mapa no seu site

  1. Gere o código de incorporação (embed/iframe) na ferramenta escolhida (OpenStreetMap, Google Meu Mapas, Datawrapper, etc.).
  2. Copie todo o código que começa com <iframe ... ou <div ....
  3. Cole o código no lugar dos blocos marcados com 📍 Cole aqui ... nesta página.
  4. Salve o arquivo mapas.html e envie para o GitHub → o Render atualiza automaticamente em ~2 min.

Não precisa de programação. Só copiar e colar.

1. Bases Geográficas — todos os repositórios

tilacog/br-atlas

TopoJSON/GeoJSON do IBGE. BSD 3-Clause. Gera Brasil, estados e municípios.

cristoferluch/GeoDadosBrasil

GeoJSON 3 níveis: mínimo (leve), intermediário, máximo. Escolha o leve para mapa rápido.

ggondim/ibge-cidades-com-poligonos

Municípios já cruzados com polígonos. Liga código do município a licitação/despesa.

0e1/localidades

Coordenadas, bandeiras, gentílicos das UFs. ODbL — exige citar fonte.

igorjba/malha

5.570 municípios com indicadores IBGE. Referência de 5 métodos de classificação de cores.

4. Google Sites — incorporação

O Google Sites não roda código do GitHub. Publique o mapa/painel no GitHub Pages (grátis, repositório luiscadilhac/brbrics) e incorpore via Inserir → Incorporar → URL. Os GeoJSON pesados devem ser substituídos pela versão simplificada para não travar no celular.
